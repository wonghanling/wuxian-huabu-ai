# 开发日志

## 2026-02-14 - 构图改为主体位置

### 修改内容

1. **构图选项改为主体位置**
   - 将"构图"维度改名为"主体位置"
   - 选项内容改为主体在画面中的具体位置
   - 根据景别类型提供不同的允许位置
   - 更符合实际拍摄场景的需求

2. **各景别类型的主体位置选项**
   - **超远景（ELS）**：左下、下中、右下、中心
   - **远景/全景**：左中、中心、右中、左下、下中、右下
   - **中远景**：左中、中心、右中、下中
   - **中景**：左中（三分线）、中心、右中
   - **中近景**：左三分、中心、右三分
   - **特写**：中心、左三分、右三分

3. **英文命名规范**
   - Bottom Left / 左下
   - Bottom Center / 下中
   - Bottom Right / 右下
   - Middle Left / 左中
   - Center / 中心
   - Middle Right / 右中
   - Left Third / 左三分（或左中三分线）
   - Right Third / 右三分（或右中）

4. **代码更新**
   - 主选项列表：`'构图'` → `'主体位置'`
   - 所有相关函数的 case 分支更新
   - 保持内部变量名 `composition` 不变（向后兼容）

## 2026-02-14 - 导演思维侧重改为可选（圆圈选择）

### 修改内容

1. **运镜固定器（必选）**
   - 运镜固定器是必选项，用户必须选择一个运镜方式
   - 标题显示"运镜固定器（必选）"
   - 每个景别类型有5个专属运镜选项

2. **导演思维侧重选项改为可选**
   - 7个选项不再是必选项
   - 用户可以根据个性需求选择任意数量的选项（至少1个）
   - 标题显示"导演思维侧重（可选）"
   - 验证逻辑：只需至少选择一个选项即可确定
   - 描述格式：只显示已选择的选项

3. **圆圈选择交互**
   - 点击主选项 → 打开右侧子选项面板
   - 每个子选项后面有一个圆形复选框
   - 点击圆圈 → 选中该子选项，自动关闭面板
   - 已选中的圆圈显示绿色对勾
   - 未选中的圆圈显示灰色边框

4. **确认逻辑更新**
   - 检查至少选择了一个思维侧重选项
   - 动态组合描述：只包含已选择的选项
   - 提示信息改为"请至少选择一个思维侧重选项"

5. **UI 优化**
   - 选项计数器：标题栏显示 `3/7`
   - 确定按钮显示已选数量：`确定 (3/7)`
   - 已选择的主选项显示绿色背景和具体值
   - 添加"全部清除"按钮：当有选项被选中时显示

6. **交互流程**
   ```
   1. 选择运镜固定器（必选）
   2. 点击主选项（如"构图"）→ 右侧弹出子选项面板
   3. 看到多个子选项，每个后面有圆圈
   4. 点击某个子选项的圆圈 → 选中，面板自动关闭
   5. 主面板显示已选择的值（绿色文字）
   6. 可以继续选择其他主选项
   7. 点击"确定"保存所有选择
   ```

### 示例

- 运镜 + 2个思维侧重：`Follow/Tracking` + `构图:Centered | 语义:Advance`
- 运镜 + 5个思维侧重：`Static` + 完整的5个维度描述
- 修改选择：再次点击已选的主选项 → 点击其他子选项的圆圈 → 更新值

## 2026-02-11 - 景别卡片系统完成

### 完成功能

1. **移除旧功能**
   - 移除景别类型选择面板
   - 移除时间线上的运镜分类功能

2. **电影控制器**
   - 添加工具栏"Film Controller"按钮
   - 鼠标悬停显示7种景别选项面板
   - 面板紧靠工具栏右侧
   - 鼠标离开自动关闭

3. **景别卡片系统**
   - 创建7种景别类型：超远景、远景、全景、中远景、中景、中近景、特写
   - 每种景别有5个专属运镜选项
   - 每种景别有7个导演思维侧重选项（必须全部选择）
   - 卡片尺寸：220x160（展开）/ 120x60（缩小）
   - 颜色方案：黑白灰背景 + 黄色标签 + 绿色输出端口 + 蓝色输入端口

4. **导演思维侧重系统**
   - 7个主选项：构图、主体比例、空间类型、时间感、光影/天气、动态来源、语义
   - 每个主选项有多个子选项
   - 必须全部选择完成才能确定
   - 已选择的选项显示绿色对勾

5. **卡片缩小/展开功能**
   - 所有卡片类型都支持：景别、文本、图片、视频、角色
   - 点击 − 按钮缩小，点击 + 按钮展开
   - 景别卡片：220x160 ↔ 120x60
   - 其他卡片：380x380 ↔ 150x80

6. **双语界面**
   - 所有景别卡片选项显示英文+中文注释
   - 英文字体 9px，中文字体 8px
   - 格式：英文在上，中文在下

- BaseBoxShapeUtil 实现卡片逻辑
- ConnectionBindingUtil 处理端口连接
