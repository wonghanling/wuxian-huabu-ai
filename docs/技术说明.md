# 技术说明

## 技术栈

- **框架：** Next.js 16.1.6 (App Router)
- **UI库：** React 19
- **画布引擎：** tldraw 4.3.1
- **语言：** TypeScript
- **样式：** Tailwind CSS

### 连接端口系统

端口结构需要两层 div：

```typescript
// 外层：接收指针事件
<div style={{ pointerEvents: 'all' }}>
  {/* 内层：阻止指针事件 */}
  <div style={{ pointerEvents: 'none' }}>
    {/* 端口视觉元素 */}
  </div>
</div>
```

ConnectionBindingUtil 处理连接位置：

```typescript
if (shapeType === 'shot-card') {
  if (binding.props.terminal === 'start') {
    return { x: bounds.maxX, y: bounds.midY }; // 右侧输出
  } else {
    return { x: bounds.minX, y: bounds.midY }; // 左侧输入
  }

```

### 状态管理

使用 tldraw editor 的 `updateShape` 方法：

```typescript
editor.updateShape({
  id: shape.id,
  type: 'shot-card' as any,
  props: {
    ...shape.props,
    cameraMovement: newValue
  },
});
```

### 缩小/展开功能

通过更新 `w`、`h` 和 `isMinimized` 属性：

```typescript
const toggleMinimize = (e: React.MouseEvent) => {
  e.stopPropagation();
  const newMinimized = !isMinimized;
  const newW = newMinimized ? 120 : 220;
  const newH = newMinimized ? 60 : 160;
  editor.updateShape({
    id: shape.id,
    type: 'shot-card' as any,
    props: { ...shape.props, w: newW, h: newH, isMinimized: newMinimized },
  });
};
```

### 多级选择系统

导演思维使用两级选择：

1. 主选项（7个可选，至少选1个）
2. 每个主选项的子选项

验证逻辑：

```typescript
// 至少选择一个选项
const hasSelection =
  composition || subjectScale || spaceType ||
  timeFeeling || lighting || motionSource || semantic;

// 动态组合描述
const selectedOptions = [];
if (composition) selectedOptions.push(`构图:${composition}`);
if (subjectScale) selectedOptions.push(`主体比例:${subjectScale}`);

const fullDescription = selectedOptions.join(' | ');
```

## 注意事项

1. **颜色规范：** 只使用绿、蓝、黄三色作为交互元素颜色
2. **端口结构：** 必须使用两层 div 结构才能正常连接
3. **类型转换：** tldraw 类型系统需要 `as any` 转换
4. **事件传播：** 按钮点击需要 `stopPropagation()` 防止触发画布事件
5. **双语显示：** 英文在上（9px），中文在下（8px）
