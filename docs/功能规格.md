# 功能规格说明

## 景别卡片系统

### 7种景别类型及运镜选项

**运镜固定器（必选）**

每个景别类型必须选择一个运镜方式，用户创建景别卡片后必须设定运镜。

#### 1. 超远景 (Extreme Long Shot)
**运镜选项：**
- Static / 固定
- Slow Push In / 缓慢推进
- Pull Out / 拉远
- Lateral Move/Pan / 横移
- Aerial/Top-down / 俯视/航拍

#### 2. 远景 (Long Shot)
**运镜选项：**
- Static / 固定
- Slow Push In / 缓慢推进
- Pull Out / 拉远
- Pan / 平移
- Tilt / 倾斜

#### 3. 全景 (Full Shot)
**运镜选项：**
- Static / 固定
- Push In / 推进
- Pull Out / 拉远
- Follow / 跟随
- Arc / 弧形运动

#### 4. 中远景 (Medium Long Shot)
**运镜选项：**
- Static / 固定
- Push In / 推进
- Pull Out / 拉远
- Pan / 平移
- Dolly / 移动车

#### 5. 中景 (Medium Shot)
**运镜选项：**
- Static / 固定
- Push In / 推进
- Pull Out / 拉远
- Pan / 平移
- Handheld / 手持

#### 6. 中近景 (Medium Close-Up)
**运镜选项：**
- Static / 固定
- Slow Push In / 缓慢推进
- Pull Out / 拉远
- Slight Pan / 轻微平移
- Handheld / 手持

#### 7. 特写 (Close-Up)
**运镜选项：**
- Static / 固定
- Slow Push In / 缓慢推进
- Pull Out / 拉远
- Rack Focus / 焦点转换
- Handheld / 手持

### 导演思维侧重选项（可选，至少选1个）

用户可以根据个性需求选择以下7个维度中的任意数量（至少1个）：

#### 1. 主体位置 (Subject Position)

根据景别类型不同，提供不同的主体位置选项：

**超远景（ELS）：**
- Bottom Left / 左下
- Bottom Center / 下中
- Bottom Right / 右下
- Center / 中心

**远景/全景：**
- Middle Left / 左中
- Center / 中心
- Middle Right / 右中
- Bottom Left / 左下
- Bottom Center / 下中
- Bottom Right / 右下

**中远景：**
- Middle Left / 左中
- Center / 中心
- Middle Right / 右中
- Bottom Center / 下中

**中景：**
- Left Third / 左中（三分线）
- Center / 中心
- Right Third / 右中

**中近景：**
- Left Third / 左三分
- Center / 中心
- Right Third / 右三分

**特写：**
- Center / 中心
- Left Third / 左三分
- Right Third / 右三分

#### 2. 主体比例 (Subject Scale)
根据景别类型不同，提供不同的主体比例选项

#### 3. 空间类型 (Space Type)
根据景别类型不同，提供不同的空间类型选项

#### 4. 时间感 (Time Feeling)
根据景别类型不同，提供不同的时间感选项

#### 5. 光影/天气 (Lighting/Weather)
根据景别类型不同，提供不同的光影/天气选项

#### 6. 动态来源 (Motion Source)
根据景别类型不同，提供不同的动态来源选项

#### 7. 语义 (Semantic)
根据景别类型不同，提供不同的语义选项

**使用说明：**
- 用户可以只选择关注的维度，不需要全部选择
- 至少需要选择1个维度
- 已选择的选项会显示绿色对勾标记
- 最终描述只包含已选择的选项
- 示例：`主体位置:Bottom Center | 主体比例:10-20% | 空间:Open Natural | 语义:Establish`

### 卡片尺寸规格

| 卡片类型 | 展开尺寸 | 缩小尺寸 |
|---------|---------|---------|
| 景别卡片 | 220x160 | 120x60 |
| 文本卡片 | 380x380 | 150x80 |
| 图片卡片 | 380x380 | 150x80 |
| 视频卡片 | 380x380 | 150x80 |
| 角色卡片 | 380x380 | 150x80 |

### 颜色规范

- **卡片背景：** 黑白灰 (#000, #fff, #gray)
- **交互按钮：** 绿色、蓝色、黄色
- **景别卡片标签：** 黄色
- **输出端口：** 绿色
- **输入端口：** 蓝色
